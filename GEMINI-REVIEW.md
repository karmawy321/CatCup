# Independent Gemini review — 2026-09-11

Verdict: partially complete; do not sign off for ordinary editing yet. The build and existing tests pass, but source inspection exposes recovery and output-correctness defects. No implementation files were changed during this review.

## Findings in priority order

1. **P1 — Recovery replacement can destroy the last valid snapshot.** `src/shell/src/Session.cpp:191–200` removes both committed recovery files before renaming the replacements. Two renames are not an atomic transaction. A crash between removal and commit, or a failed rename, can leave no recoverable project; the failure branch also deletes committed paths. This is in the new diff. Preserve the previous generation until one atomic commit makes a complete new generation authoritative. Include metadata and project content in one atomic envelope, or use immutable generations and an atomic pointer. Test injected failures at every commit boundary, including an existing valid snapshot. Hash rejection of mismatched files is useful, but does not preserve the previous snapshot.

2. **P1 — Export composition is not equivalent to preview, including the new resolution override.** `src/export/ffmpeg/src/Mp4Exporter.cpp:200–216` copies/crops untransformed, effect-free decoded frames at native dimensions instead of fitting them. The new override at lines 387–388 changes the composition canvas without fixing that path. A 1280×720 source exported at 1920×1080 therefore remains a centered 1280×720 picture with black borders; a larger source can be cropped. An otherwise neutral effect bypasses this path and changes framing. Preview instead fits the image in `src/shell/src/FrameCompositor.cpp:193–201`. Export also does not apply `rotationDeg`, while preview does, and export title size/offsets at lines 440–442 are not scaled with output resolution. Native-size copying and missing rotation predate this diff; the new override exposes the size problem as a selectable workflow. Use equivalent composition semantics and scale the completed sequence image, or consistently transform sequence coordinates to output coordinates. Verify actual pixels, not just output dimensions or the summary string.

3. **P2 — A failed save leaves a latent destructive action.** `src/shell/qml/Main.qml:538–551` executes any nonempty `pendingAction` after a successful Save As. Failure branches there and at lines 639–641 leave that action intact. Example: request Quit, choose Save, encounter a save failure, continue editing, then use ordinary Save As; its eventual success also executes the old Quit. Clear or explicitly retain/re-present the pending transaction as part of the failure UI. Test the QML action flow, not only `Session::saveAs()`.

4. **P2 — Project details are misleading and Modify silently does nothing without selection.** Live empty-project inspection shows a 1280×720 preview badge alongside `1920×1080 (1280x720)` in Details. `src/shell/qml/Inspector.qml:192` hardcodes 1920×1080; lines 240–247 enable a clickable Modify control whose handler only acts when a clip is selected. Display real sequence dimensions and make Modify open supported project settings or disable it with an explanation. These remain unmet requirements; not established as new regressions.

5. **P2 — Failed/cancelled overwrite can remove the previous export.** `src/export/ffmpeg/src/Mp4Exporter.cpp:553–562` deletes the destination on failure, and line 661 opens that destination directly for writing. Once overwrite is confirmed, cancelling or failing the replacement can lose the previous output. This behavior predates the diff. Export to a sibling temporary file and replace the destination only after successful completion; test cancellation/failure with a pre-existing sentinel output.
